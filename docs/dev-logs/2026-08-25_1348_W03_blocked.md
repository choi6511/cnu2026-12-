## 3. 구현 판단

- 선택한 구조 또는 접근: 키 값을 출력하거나 브라우저 네트워크 URL을 노출하지 않고, 서버 측에서 `.env.local` 값을 메모리로 읽어 Kakao SDK에 요청한 뒤 응답 상태·오류 종류만 출력했다. 브라우저에서는 SDK 호스트·경로와 appkey 파라미터 존재 여부만 확인했다.
- 공식 설정 근거: Kakao Developers 공식 카카오맵 문서는 앱 관리 페이지의 `[카카오맵] > [사용 설정]`에서 상태를 `ON`으로 바꾸고, Web SDK는 JavaScript 키에 JavaScript SDK 도메인을 등록하도록 안내한다.
- 대안과 선택 이유: 지도 API 비활성화를 앱 코드에서 우회하거나 mock 지도를 성공으로 취급하지 않았다. W03 완료 조건은 실제 Kakao 지도이므로 외부 설정이 활성화된 뒤 라이브 성공 경로를 다시 검증해야 한다.
- PRD 또는 기존 구현과의 관계: GPS를 요청하지 않고 SDK 오류 시 정적 장소 목록과 안내를 유지하는 기존 구조는 그대로 보존했다.

## 4. 문제 및 막힌 지점

- 증상: 새 키 저장 후 Kakao SDK 요청이 HTTP 403을 반환하고 모바일 화면은 `data-map-status="error"`, 타일 0개, 라벨 0개로 표시됐다.
- 재현 방법: `.env.local` 수정 후 Kakao SDK URL을 키 마스킹 방식으로 요청하고, 로컬 앱 `/`을 320×800 브라우저에서 열어 SDK 전역·지도 상태·DOM을 확인했다.
- 원인: Kakao 응답은 `NotAuthorizedError`와 `App(충남대 안내 맵) disabled OPEN_MAP_AND_LOCAL service.`를 반환했다. 이전 Admin 키 문제는 해소됐지만 해당 앱에서 카카오맵 API 사용 설정이 꺼져 있다.
- 영향을 받은 범위: 온라인 Kakao 지도 타일, 세 마커·라벨, 지도 요소를 통한 장소 소개 이동 성공 검증이 막혔다. 오류 안내와 정적 장소 링크는 정상 표시된다.

## 5. 해결 방법

- 시도한 방법: 키 존재·길이와 Git 제외를 재확인하고, Kakao SDK 응답과 브라우저의 `window.kakao`, 타일·라벨 수, 오류 오버레이를 각각 확인했다.
- 현재 필요한 해결책: Kakao Developers의 `충남대 안내 맵` 앱에서 `[카카오맵] > [사용 설정] > [상태]`를 `ON`으로 변경한다. 이어 `[앱] > [플랫폼 키] > [JavaScript 키] > [JavaScript SDK 도메인]`에 `http://localhost:3000`이 등록되어 있는지 확인한다.
- 같은 문제가 재발할 때 확인할 항목: 지도 사용 상태, 무료 쿼터 적용 앱 여부 또는 비즈월렛 요구 여부, JavaScript 키 활성 상태, SDK 도메인을 순서대로 확인한다. 키 값과 appkey가 포함된 전체 URL은 로그에 남기지 않는다.
