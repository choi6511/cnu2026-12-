## 4. 미해결 사항 및 위험

- 시네마틱 연출은 CSS perspective와 제공 자산 기반이며, WebGL/Three.js 실시간 3D 캠퍼스 모델은 아니다.
- friend-owned Vercel 프로젝트는 현재 세션의 Vercel 플러그인에 노출되지 않아, plugin dashboard의 deployment record는 직접 조회하지 못했다. 대신 공개 HTTPS 응답을 확인했다.
- W10–W15의 Apify 공지 실데이터·전체 통합 검증은 이 시각 개선 작업 범위 밖이며 여전히 별도 진행 조건이다.

## 5. 다음 작업 지침

- 발표 기기에서 설치 후 홈/장소 소개/도감의 cold offline 동작과 새 Service Worker 갱신을 다시 확인한다.
