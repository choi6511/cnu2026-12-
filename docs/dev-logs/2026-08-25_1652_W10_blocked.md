- 증상: 현재 도구 목록에서 Apify 관련 도구가 0개다.

- 원인: 이 Codex 세션에 Apify MCP OAuth 연결이 로드되지 않았다.
- 영향을 받은 범위: 세 출처 수집, `crawl_runs` 기록, 공지 UI 실제 데이터 검증.
