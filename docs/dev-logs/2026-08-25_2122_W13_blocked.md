## 작업 개요

PWA manifest, 아이콘, Service Worker, 정적 오프라인 안내 구현을 로컬에서 점검하고 설치·오프라인 완료 조건을 검증했다.

## 검증 결과

- `/manifest.webmanifest`가 `standalone`, `ko-KR`, 192x192·512x512 PNG 아이콘을 반환한다.
- 로컬 홈 화면과 정적 라우트가 정상 렌더링된다.
- `npm test`: 9개 파일, 33개 테스트 통과.
- `npm run typecheck`, `npm run lint`, `npm run build`: 모두 통과.

## 문제 및 막힌 지점

현재 in-app Browser 런타임에는 `navigator`/Service Worker API가 노출되지 않아 실제 worker 등록·활성화를 확인할 수 없다. 또한 W14 기록처럼 Vercel 프로덕션 URL이 최신 GitHub 커밋을 서빙하지 않아 HTTPS 모바일 Chrome 설치·오프라인 검증을 수행할 수 없다.

## 해결 방법 및 다음 행동

코드와 정적 검증은 통과했으므로 새 코드를 추측해 수정하지 않는다. Vercel 프로젝트 소유자가 최신 `main`을 Production으로 재배포한 뒤 모바일 Chrome에서 설치, 오프라인 홈·장소·도감, 지도/공지 offline fallback, 새 배포 갱신을 확인한다.
