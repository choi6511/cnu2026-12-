# 개발일지 — W16 선택 개선: CHA-CHA 원본 자산 정정

## 작업 개요

- 사용자 피드백에 따라 hero에서 잘리거나 회전되어 보이던 마스코트 표현을 정정했다.
- `CHA-CHA)Design System/assets/mascot-front.png`의 원본 정면 캐릭터를 홈 hero에 사용하고 전체가 보이도록 배치했다.
- 도감에는 `pose-together.png`, 최초 획득 dialog에는 `face-cheer.png`를 원본 그대로 추가했다.

## 구현 판단

- 제공된 공식 PNG는 재색칠·반전·회전·비율 왜곡하지 않았다.
- continuous mascot motion과 3D rotation을 제거하고 opacity entrance만 남겼다. 사진 카드의 CSS perspective는 캐릭터 원본에 적용하지 않는다.
- OneDrive가 기존 `.next` directory를 잠글 수 있어 Next output을 gitignored `.next-build`로 옮겼다. Next가 요구한 type include도 `tsconfig.json`에 반영했다.

## 검증 결과

- 390×844 local mobile viewport에서 전체 CHA-CHA 정면 마스코트가 잘리지 않고 표시됨을 확인했다.
- `npm run typecheck`, `npm run lint`, `npm test` 통과 (26 tests).
- `npm run build` exit code 0, 14개 static pages 생성.

## 미해결 사항 및 다음 작업

- production에는 이 정정 커밋이 병합·Vercel 배포된 뒤 public HTTPS에서 다시 확인해야 한다.
- WebGL 3D 모델은 이 작업 범위가 아니다. 현재는 공식 캐릭터 자산을 보존한 CSS 기반 시네마틱 UI다.
