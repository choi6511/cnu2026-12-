# 개발일지 — W12 장소별 최근 공지 UI

## 메타데이터

- 상태: `진행 중`
- 작업 ID: `W12`
- 일시: `2026-08-25 20:45–20:55 KST`

## 작업 개요

현재 구현된 장소별 최근 공지 화면을 실제 Supabase 데이터와 연결해 검증했다.

## 변경 사항

- 코드 변경 없음. 기존 `PlaceNoticeList`의 source별 조회, KST 최근 7일 경계, 빈 상태, 마지막 성공 갱신 시각, 오류·오프라인 상태를 점검했다.

## 검증 결과

- Supabase `notices`: library 10건, language-center 10건, industry-center 10건.
- 최신 게시일: library 2026-08-23, language-center 2026-08-19, industry-center 2026-08-17.
- `crawl_runs`: 세 출처 모두 success, 각 item_count 10.
- 개발 서버에서 `/places/library/notices` HTTP 200 응답 확인.

## 문제 및 막힌 지점

개발 서버 종료 후 `node_modules`가 불완전한 상태가 되었고, `npm ci`가 TAR_ENTRY_ERROR를 내면서 `next`, `vitest`, `eslint` 실행 파일을 복원하지 못했다. 따라서 W12 완료 게이트인 자동 테스트·타입 검사·린트·빌드를 다시 통과시키지 못했다.

## 다음 작업 지침

`node_modules`를 깨끗하게 복원할 수 있는 환경에서 `npm ci` 상태를 먼저 확인하고 `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`를 재실행한다. 통과하면 이 일지를 `W12_complete`로 새로 남긴다. 이후 W13으로 이동한다.
