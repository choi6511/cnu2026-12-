## 1. 작업 개요

- 이번 작업 단위에서 만들기로 한 것: 장소 소개 화면의 캐릭터 획득 완료 카드 원형 안에 획득한 장소의 캐릭터를 작게 표시한다.
- 실제로 완료한 범위: 기존 IndexedDB 획득 상태를 재사용해 획득된 경우에만 캐릭터 이미지를 원형 안에 렌더링하고, 이미지가 원 밖으로 나오지 않도록 마스크 처리했다.
- 범위에서 제외하거나 다음으로 넘긴 것: 도감 화면, 획득 판정, 캐릭터 자산과 방문 인증 흐름은 변경하지 않았다.

## 3. 구현 판단

- 선택한 구조 또는 접근: `hasCollectionRecord`의 기존 결과를 재사용하고, 획득 상태일 때만 `characterImagePath`를 표시했다.
- 대안과 선택 이유: 별도 저장값이나 이미지 변환을 만들지 않았다. 장소의 정적 캐릭터 자산을 사용하면 도감과 카드의 캐릭터가 항상 일치한다.
- PRD 또는 기존 구현과의 관계: 인증사진은 계속 IndexedDB에만 저장하며, 서버 전송·새 보상 기능은 추가하지 않았다.

## 4. 문제 및 막힌 지점

- 증상: 획득 완료 카드의 원형 표시가 빈 색상 원으로만 보였다.
- 재현 방법: 방문 인증 완료 후 장소 소개 화면을 다시 연다.
- 원인: 상태 표시 컴포넌트가 텍스트만 렌더링하고 캐릭터 이미지 경로를 받지 않았다.
- 영향을 받은 범위: 장소 소개 화면의 획득 완료 카드.

## 5. 해결 방법

- 시도한 방법: 상태 컴포넌트가 원형 표시와 설명을 함께 반환하도록 구성했다.
- 최종 해결책: 원형 컨테이너에 `overflow: hidden`, 이미지에 `object-fit: contain`과 여백을 적용했다.
- 같은 문제가 재발할 때 확인할 항목: 새 캐릭터 자산이 투명 배경인지와 원형 컨테이너의 고정 크기·overflow 속성을 확인한다.
