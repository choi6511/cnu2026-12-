- 상태: `완료`

- 일시: `2026-08-25 20:45–21:12 KST`

## 작업 개요

장소별 공지 화면이 Supabase 실제 데이터에서 source별로 분리된 최근 7일 공지를 읽고, 마지막 성공 갱신 시각과 빈 상태·오류·오프라인 상태를 표시하는지 검증했다.

## 변경 사항

- 손상된 `node_modules`를 프로젝트 경로에서 제거하고 `package-lock.json` 기준으로 재설치했다.
- 기존 `PlaceNoticeList` 구현을 실제 Supabase 데이터와 함께 재검증했다.
