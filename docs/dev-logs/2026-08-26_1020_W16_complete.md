## 1. 작업 개요

- 이번 작업 단위에서 만들기로 한 것: 홈 히어로의 한글 제목·설명 줄바꿈과 글자 간격을 모바일·넓은 화면에서 읽기 좋게 정리한다.
- 실제로 완료한 범위: 제목의 단어 중간 줄바꿈을 막고, 과도한 음수 자간·폭 제약을 제거했으며 한국어 폰트 fallback과 한국어 단어 단위 줄바꿈 규칙을 보완했다.
- 범위에서 제외하거나 다음으로 넘긴 것: 화면 구조·이미지·하단 내비게이션 기능 변경은 하지 않았다.

## 3. 구현 판단

- 선택한 구조 또는 접근: 전체 리디자인 대신 히어로 제목의 원인인 `max-width: 9.5ch`, 강한 음수 자간, `overflow-wrap: anywhere`를 최소 수정했다.
- 대안과 선택 이유: 임의의 줄바꿈이나 이미지 크기 변경으로 덮지 않았다. 제목과 문단 모두 한국어의 단어 단위 줄바꿈 규칙을 사용해야 다른 화면에서도 같은 문제가 줄어든다.
- PRD 또는 기존 구현과의 관계: 모바일 우선·기존 시각 디자인을 유지하고 텍스트 가독성만 개선했다.

## 4. 문제 및 막힌 지점

- 증상: 히어로 제목이 글자 단위로 분리되고 강한 음수 자간으로 겹쳐 보였다.
- 재현 방법: 홈 화면에서 `오늘의 캠퍼스를 발견합니다` 제목을 넓은 뷰포트로 확인한다.
- 원인: 제목 폭이 `9.5ch`로 제한되고 `overflow-wrap: anywhere`, `letter-spacing: -0.075em`이 함께 적용됐다.
- 영향을 받은 범위: 홈 히어로 제목과 긴 한글 문장의 가독성.

## 5. 해결 방법

- 시도한 방법: 제목 줄을 블록 요소로 고정하고 `white-space: nowrap`, `word-break: keep-all`을 적용했다.
- 최종 해결책: 반응형 크기를 낮추고 `max-width`를 제거해 한 줄의 단어가 정상 폭을 확보하도록 했다.
- 같은 문제가 재발할 때 확인할 항목: 한글 제목에 `ch` 기반 폭 제한, 과도한 음수 자간, `overflow-wrap: anywhere`가 함께 쓰이지 않는지 확인한다.
