Standard surface. `plain` for content, `elevated` for interactive tiles, `accent`/`cream` for tinted callouts, `inverse` for navy panels.

```jsx
<Card label={<PillLabel ko="주요 포즈" en="POSES" />} title="응원하는 차차">
  경기장과 행사에서 쓰는 기본 응원 포즈입니다.
</Card>
```

Never add a colored left border. Pair with `PillLabel` for section-level cards.
